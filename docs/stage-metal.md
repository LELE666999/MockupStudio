# 金属编织网

视觉方向：中性不锈钢、连续圆丝、克制的柔光高光；用实际曲面和反射层次体现材质，不依靠发光描边。

界面范围：保留现有编辑器与场景入口，更新网格的实体结构、默认材质和生产几何缩略图。

交互方向：环绕视角时高光连续变化；远近缩放保持真实网孔；选中、摆放、存档和导出沿用原有流程。

## 实现

- `lattice` 的存档标识不变。圆丝沿两个方向以相反相位交织，边框倒角，立柱与横梁接合而不重叠顶面。
- 索引几何合并为边框、网丝两个材质组，每个方向最多 28 格；每格 6 段纵向曲线，截面 8 段，平滑法线。
- 金属度为 1，无清漆、无透射；边框和网丝使用不同拉丝强度与粗糙度。用户颜色、粗糙度和灯光颜色仍有效。
- 场景展台共享程序化柔光棚 PMREM，金属使用专门的微粗糙度纹理。手机屏幕继续使用自己的渲染路径，不给屏幕叠加高光或灰雾。
- 一组网台共享反射与微粗糙度纹理；相机拖动、展台移动不重新生成。退出场景时释放自有资源。
- 金属场景降低方向光硬阴影强度，配合单独校准的深度偏移，保留投影与接收阴影，减轻细网丝在高光倒角处产生的斑点。无场景与石材场景的阴影保持不变。
- 不改变保存格式；旧网格存档载入时直接使用新结构，保留原有位置、角度、尺寸、颜色和粗糙度。

## 验证

`stageMetal.test.ts` 检查交织、网孔、预算、极端尺寸和材质控制；`check-stage-metal.mjs` 检查离线加载、反射缓存、屏幕隔离、远近与角度截图、粗糙度、主题、场景切换和模型面板。

`check-detailed-stages.mjs` 检查平躺/竖立/侧放、真实 FBX、存档重开与 PNG/MP4 导出。`bench-detailed-stages.mjs --metal-only` 使用真实 Pura FBX 拖动视角，分别测量景深开关，不降低转动时的景深质量。

物理材质及预滤波反射实现参考 Three.js r173 官方 [MeshPhysicalMaterial](https://github.com/mrdoob/three.js/blob/r173/docs/api/en/materials/MeshPhysicalMaterial.html) 与 [PMREMGenerator](https://github.com/mrdoob/three.js/blob/r173/docs/api/en/extras/PMREMGenerator.html) 文档。
