# 简单阔折叠样机

入口：模型 → 简单 → 阔折叠样机。默认直板样机保持不变。

参考 [华为 Pura X Max 官方尺寸](https://consumer.huawei.com/cn/phones/pura-x-max/specs/)（展开 166.5 × 120 mm）的横向比例，使用程序生成的双壳、内藏开合轴、柔性折弯区、相机与侧键。不是官方模型或真实铰链机械工程复刻；不需要下载模型文件。外屏在模型局部左半机背，相机在右半机背；不再使用外露的分段圆柱或独立亮色边条。更新位置不改变内外屏的素材引用。

内屏与机背外屏可分别导入媒体。外屏使用 `coverScreenshot` / `coverScreenshotType`，随同模型和关键帧打包，替换时同步对应旧媒体的关键帧，不覆盖内屏。两段视频均从项目时间 0 开始，暂停/拖动/导出跟随同一时间轴，到各自末帧停止而不循环。外屏默认居中裁切填满；转到机背可查看。

- `simpleStyle: fold`、`foldAngle: 0..180` 随模型保存；旧项目缺省仍是直板。
- 0° 合拢、90° 半开、180° 平展。合拢后内屏朝内，正视铰链会看到侧面，可旋转整个模型展示机背。
- 两个机壳沿柔性圆弧端部切线转动；中心屏幕使用密集弯曲网格，UV 始终来自展开态，没有两份视频或中缝重复。
- 视频沿用时间轴同步、换片、导出等待机制。展开角度进入逐段与连续插值，也可和旋转、位移一起打关键帧。
- 无关键帧时可生成 3 秒 0° → 180° 的展开动画；已有关键帧时不替用户覆盖时间轴。
- `npm test` 覆盖几何连续性、UV、动画和文件往返；`node scripts/check-foldable.mjs` 在独立浏览器验证三种角度、视频、两种曲线、保存与刷新，并实际导出 3 秒 MP4。
