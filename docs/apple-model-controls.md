# 苹果机身改色与 Duo 开合

> 此文说明原本地版本的可选模型适配代码。公开版不分发 Apple 模型，不提供这些内置按钮；需要用户自行取得合法模型。公开版自制动态折叠入口为「简单 → 阔折叠样机」。

## 入口

模型 → 高级 → 苹果 Apple。机身 / 外框颜色控制机壳、金属边框、按键和同色饰件；
屏幕黑边、镜头玻璃、屏幕内容和印刷标识不整体染色。原始配色可还原原材质。

补全 iPhone 17 的端口/饰件，以及 Duo 的铰链、按键、机身与外框材质映射。
内置资源路径与带原文件名的项目恢复使用相同映射，未知导入模型不凭颜色猜测材质。
颜色关键帧同时插值 RGB 并启用改色，避免输入框变色但仍显示烘焙配色。

## Duo

仅对内置 `iphone-duo.glb` 做已知结构的铰链重建；普通直板 iPhone 不会被强行折弯。
原文件没有动画，两个半机身的局部几何仍保留展开建模坐标。
重建复用原机身、摄像头、按键、外屏细节，将旧闭合内屏和导出包围体替换为一张连续内屏。

- 新选 Duo 默认平展，展开角度 0–180°；可合拢、半开或完全展开。
- 开合只改变两侧刚性组的矩阵和连续内屏的小型缓冲区，不重新加载手机模型或视频。
- 内屏 UV 和宽高比不随角度改变，视频不会因合拢而重新裁切。
- 内外屏分别使用独立视频，并跟随同一时间轴；短片到末帧停止。
- 展开角度支持逐段曲线、连续平滑、项目存档与视频导出。
- 没有展开角度的旧 Duo 项目仍按合拢处理；原有外屏选面与媒体保持原目标。

单独观察闭合外屏可点击「查看外屏」。固定正面视角下，向内合拢会看到折叠侧面；
整体手机旋转仍由现有位置/旋转参数与关键帧独立控制。

## 回归检查

`npm test`、`npm run lint`、`npm run build`。
`node --experimental-strip-types scripts/check-apple-models.mjs --export` 在实际 file:// 网页里检查
五款苹果预设、改色与原配色还原、三档开合、稳定几何和 UV、双视频、两种曲线、存稿恢复与 MP4 导出。
