# 三套极简摄影棚

视觉主旨：以手机为唯一视觉主体，用深蓝冷光、银灰建筑玻璃、蓝白柔光三种克制棚景区分气氛；不靠粗糙噪声与大量道具增加细节。

内容计划：三张实际渲染缩略图作为入口，沿用现有环境编辑器；保留原场景，手机媒体不替换。

交互主旨：选预设同时应用构图、灯光和镜头；手机、展台与背景构件可独立调整，相机、手机移动和时间轴播放让空间与玻璃倒影联动。配置进入原有项目存档与导出。

深蓝斜台新增纯色/多色光：纯色的三个大面光保持同一色相与亮度层次；多色的主光、轮廓光、补光可以分别选择。背景渐层、大面光和反射环境使用同一配色；屏幕媒体保持不受灯光影响。可选冷蓝、极光、落日快捷配色，切回纯色不丢失多色的备选颜色。自定义背景图/背景颜色仍优先于预设渐层。配置存入 stage.studioLighting，旧项目没有此字段时仍能打开。

验证：npm run lint、npm test、scripts/check-minimal-studios.mjs（离线实际手机与媒体、构图、光色、实时倒影缓存、项目保存恢复、视频导出）。缩略图使用该检查的 --visual --thumbnails 从真实编辑器画面生成；旧材质图使用 scripts/render-stage-thumbnails.mjs。
