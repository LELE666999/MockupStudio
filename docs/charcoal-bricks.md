# 炭黑粗砖场景

入口：环境 → 有场景 → 炭黑粗砖。选择后将第一台可见手机斜躺在砖面上，
镜头按手机实际包围盒取景；手机媒体、尺寸、其它手机与关键帧不变。

视觉方向是湿润炭灰多孔粗砖、窄深砖缝、不规则细苔斑、克制擦边光和接触阴影。
沿用编辑器的场景选择、视角、摆放、颜色与置换控制，仅在砖景内增加雨水设置。

## 几何与材质

- 新砖景默认 45 块封闭砖体，错缝排列，一次 indexed draw：50,008 顶点 / 85,660 三角形。
  行数/列数可在 2–10 间调整，范围联动扩展；旧存档未设置行列数时仍为原来的 10 块。
- 真实边角缺损、砖缝和侧面厚度；不是参考照片贴在一个平面上。
- 其中 13 块有真实、浅而不规则的磨损凹槽，局部细分以形成平滑槽底；
  凹槽避开圆角和 UV 接缝。关闭雨水后凹槽仍然存在，但没有水面。
- Poly Haven Rough Concrete 原始 CC0 PBR 材质。1K albedo / AO / roughness、
  2K OpenGL normal；原始高度 PNG 下采样为 256² CPU 双线性采样场。
- 低频置换只在尺寸、密度、起伏等几何参数编辑时烘焙。旋转视角与改颜色
  不重新生成几何；细小颗粒采用 mipmaps / anisotropy，避免远景闪烁。
- 高度只从支撑面向内雕刻，手机摆放不穿入随机凸起。
- fragment-only albedo 去除原始水泥的黄褐色，让可编辑颜色保持主导；
  金属机身、屏幕内容和视频不受处理影响。该 shader 不改变阴影几何。
- 完整存档接受 brick-court 类型，离线 HTML 包含全部材质，无运行时联网。

## 实时雨景

- 默认开启细雨，支持雨量、滴径、风向、湿润度和静止预览开关。
  青苔单独可调；关闭雨水时砖面恢复干燥。关闭静止预览可以检查时间轴单帧。
- 真实加载的手机网格与置换砖面三角形生成 256² 顶部碰撞图，记录最高表面和法线。
  隐藏网格、控制轴和雨水自身不参与碰撞；砖面图缓存复用，手机变化仅重算手机图。
  相机环绕、时间推进与雨量变化不重建碰撞图或砖几何。
- 640 个固定种子落点，GPU 解析下降与三方向重力飞溅；飞溅从表面法线方向发射。
  少量手机落点重要性采样使近景能看到接触；不是贴在画面上的全屏雨线。
- 玻璃采用 IOR 1.333、低粗糙度的透射水珠；逐渐生长的水珠、短扩散痕随手机移动。
  表面水加入对应手机/砖面的景深图层，避免透明叠层穿帮或遮坏录屏。
- 湿砖不再启用 clearcoat，也不把粗糙度拉低到亮漆水平。湿斑主要变深，
  保留多孔石材的粗糙反射；降低石材反射强度，避免圆角出现连续白线。
- 根据凹槽最低点和实际溢流边缘计算水位，湿润度控制填充量；
  三角形按水位裁剪出不规则岸线，排除高处、砖缝及手机遮挡。
  水面在世界坐标中保持水平；默认每个砖场仅用一份合并水面几何。
- 雨滴碰撞停在保留的水位，少量水洼落点重要性采样确保近景可见。
  扩散、干涉、衰减的波法线直接作用于整片水面，不再逐滴叠加圆形平面。
  每份水面最多 48 组波包，共享时间轴时钟；按真实水面岸线截断。
- 水采用 IOR 1.333、无蓝色漫反射填色的薄层 Fresnel 混合，底部砖纹保持可见；
  反射随视角和摄影棚环境变化，不使用发光白圈。
  手机玻璃仍使用很短的细扩散痕，避免盖住录屏。局部湿痕与立体细叶青苔共存。
  所有雨水与苔叶均为批量几何，不为每滴创建对象；雨水不反复更新静态阴影。
- 播放与导出直接使用 `currentTime`，不使用真实耗时。静止预览的额外时间不进入存档或导出。
  两台手机、旋转/移动手机、切换雨水、存档恢复和 MP4 导出均有真实离线浏览器检查。

这是实时颗粒/表面水的近似模型，不是离线流体模拟：不会求解连续水流、体积守恒、
水珠之间的真实合并或任意方向的液体碰撞。碰撞图以重力方向为主，适合当前砖场近景；
细微风偏由雨滴路径表现。原始媒体、手机尺度与关键帧不会被雨水功能覆盖。

## 验证

`npm run lint`、`npm test`、`npm run build`

`node --experimental-strip-types scripts/check-brick-studio.mjs --thumbnails --rain --export`

检查真实 file:// 编辑器里的材质、手机与媒体保留、视角复用几何、改色、
置换、项目导出/重开、退出场景、模型面板、摆放与短视频导出。
雨景检查还覆盖暂停/预览时钟、两台手机的独立表面水、变换更新、开关回收和帧间变化。

刷新离线资源：`node scripts/build-offline.mjs`。
下载校验：`node scripts/download-brick-material.mjs`，逐文件校验原始 MD5。
