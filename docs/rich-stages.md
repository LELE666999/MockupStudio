# 细腻场景与软接触

视觉主旨：表面微细节与中尺度轮廓都来自对应材质的实体结构，保留干净产品摄影和原有编辑布局。内容主旨：场景缩略图由实际生产几何生成，不用参考照片掩盖实际效果。交互主旨：少量紧凑参数调整材质、密度、置换和压陷；操作手机/视角时不重新生成表面。

保留金属编织网和已有场景 ID。场景库现有十二套：羊毛针织、绞花毛衣、亚麻、丝绒、毛绒、自然岩台、金属格栅、细纹石台、方形展台、错层石台、玻璃组合、阶梯陈列。

## 材质与光

- 毛衣使用周期交错的实体纱线和立体捻线截面，绞花使用实体编织束；不是把凹凸图直接贴在平面。每件针织合为一个索引网格，最多 150,000 三角形，有共享褶皱、接触压陷及一致的阴影深度；单批最多 6,000 根真实短毛羽长在实际纱线表面，避免光滑塑料绳的观感。
- 亚麻使用实体交替经纬扁圆纱线，横向覆盖约 84%，保留交织高差，线头藏入布边，避免稀疏铁网观感；加离线织物法线、粗糙度和中性底色。丝绒有短立体纤维和物理 sheen，不用发光描边模拟绒光。颜色可编辑。
- 毛绒是有弯曲、渐细和长度变化的立体纤维，单组实例化几何，最多 36,000 根；每根纤维六个顶点、四个三角形，不为每根毛创建独立对象或绘制重叠的双卡片。
- 洞石、板岩、水磨石、混凝土和自然岩石增加实际共边细分及顶点置换，分别形成孔隙、层理、浅浮雕、孔洞和断口。UV 缝共享几何位置与法线，保留可摆放手机的中央支撑区域；每件石材限制 96,000 顶点 / 156,000 三角形。精加工玻璃/金属保持倒角、厚度、透射或圆丝结构，不强加石头噪声。
- 场景共享缓存柔光棚反射，加三盏宽面柔光源；手机屏幕继续走原有无反光的贴图路径，不把屏幕黑色冲成灰雾。
- 材质按钮使用紧凑的三列圆角矩形，沿用编辑器主题；不重新布局模型、文字、时间轴和视角面板。

## 接触压陷

这是实时视觉接触模拟，不是全布料刚体动力学。把手机底部的包围体裁切到台面接触层，再转成台面局部坐标里的有方向接触区域。平躺压一片，竖立压底边，侧放、旋转或移动后重新计算；悬空、移开或关闭压陷则恢复。

底面位移、表面法线、阴影深度、针织/亚麻纱线和毛绒纤维使用同一组压陷参数。纤维和实体针脚在手机内部被压低到手机底部以下，边缘逐渐变形。最多同时处理八个接触区域；两个手机可分别压绒。

仅模型/台面变换和尺寸变化会重新计算接触。相机环绕不遍历每个模型顶点、不重建毛绒、不重烘焙反射。几何包围盒、纹理和反射缓存复用，切换或退出场景释放自有资源。预览和导出使用同一套几何变形。

景深分层渲染共用固定灯光的静态阴影缓存：只改变观察相机时不额外重绘整场阴影；手机/展台几何与变换、灯光、透明裁切、位移纹理、接触压陷或 WebGL 上下文恢复会使缓存失效。相同接触不重复使缓存失效；显式阴影更新请求只在成功渲染后消费一次。骨骼及未知顶点着色器保持动态更新。阴影刷新时被丢弃的颜色预渲染使用 1×1 目标，但保留原阴影贴图尺寸和光源视锥，没有在拖动时减少景深采样、降低分辨率或切换轻量模糊。

石材细分拓扑及单位深度位移场使用有界 CPU LRU 缓存（最多 6 项 / 320,000 顶点）；置换深度调整不重新细分或计算噪声，但生成独立可释放的 GPU 几何。本机初次建立约 290–365 ms，后续滑块调整约 4–10 ms。不同台面和输出不共享可变几何。

颜色、形状、石材表面、织纹密度、针织纹样、置换深度、压陷强度、毛长、毛密度、位置、角度和尺寸全部跟随完整 `.mockup3d` 存档，无需保存额外外链资产。

- `scripts/check-stage-metal.mjs`、`scripts/check-model-panel-selection.mjs`、`scripts/check-camera-view.mjs`：已有效果、模型面板与独立视角控制回归。

测试使用独立临时浏览器，不读取或修改用户当前浏览器草稿。
