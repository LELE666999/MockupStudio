# 蓝紫凹槽展台

视觉主旨：深紫缎面围绕冷蓝的圆角压纹展台，以真实凹槽、细密编织反光和干净的手机屏幕形成层次。

内容计划：在现有场景库中增加一个实际渲染预览入口；沿用灯光、物体和相机编辑，不增加独立工作流。

交互主旨：选中预设后手机平躺在左侧承托区；斜俯视、正俯视和近景仅改变相机，不覆盖手机媒体或关键帧。主光、轮廓光、补光可分别选色，场景、材质和视角随项目保存与视频导出。

几何与质感：圆角展台使用连续索引网格，四条胶囊形凹槽是真实向下的曲面；缎面使用有法线的三维褶皱。微织纹颜色、法线和粗糙度贴图包含 mipmaps 与各向异性过滤，保持近景细节而不让远景闪烁。静态几何与纹理不会随相机移动重建。

验证命令：`npm run lint`、`npm test`、`node scripts/check-minimal-studios.mjs --grooved --thumbnails`。浏览器检查使用隔离的离线 Chrome 和真实内嵌 iPhone GLB，检查三个视角不改模型或媒体、几何重用、光色修改、存档恢复、视频导出及小屏控件。`public/scenes/grooved.png` 来自真实渲染，不是参考图或背景贴纸。原有棚景和模型面板检查分别使用 `scripts/check-minimal-studios.mjs` 和 `scripts/check-model-panel-selection.mjs`。
